This tenant has no repositories yet. Myelin creates a repository the first time you push to it — there's nothing to set up here first.

Get your first repository in

1
Point a local repo at Myelin 
git remote add myelin https://git.eu.myelin.dev/acme/<name>.git
Swap <name> for your repository name — that's what it will be called.
2
Push your default branch 
git push -u myelin main
The repository is created on this first push. No “New repository” button — the push is the create.
3

  • Your repository appears in this list.
  • Open a pull request to propose changes.
