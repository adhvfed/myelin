README.md

Myelin

One EU-sovereign, agent-native platform that fuses git hosting, CI/CD, an issue tracker, a knowledge base, and chat — five subsystems that read as one product.

Why one product

Coherence is the feature. The same ArtifactRef renders the same chip everywhere; the same Principal renders the same badge everywhere.

Getting started

git clone git@myelin.dev:acme/myelin.git
cd myelin
cargo build --workspace
cd frontend && pnpm install && pnpm dev

Layout

  • crates/ — the Rust backend (git, authz, edge, gateway).
  • frontend/ — SolidStart web app + the design-system package.
  • planning/ — architecture, ADRs, the release-track ledger.

See planning/02-holistic-architecture/design-language.md for the point of view, and the live styleguide for the real tokens.
