Description

The live edge authorized git JSON reads by action only — any authenticated principal could read every repo's PRs, commits and blobs by URL. This routes every JSON read through check(object, action) on the fully-qualified object and adds the list_objects pre-filter so restricted repos are absent, not greyed. Closes SEC-341 Action-only authz exposes every repo's JSON API.

Design context: AuthZ ruleset design — object-level checks. Cross-tenant reads return not-found, never 403 — the anti-oracle rule.
