Theme

The living styleguide for the recommended visual direction A “Instrument” (midnight command-deck: neutral-led, one rationed electric-blue accent, near-zero radius, hairlines-first, compact default, crisp motion). Every pixel below is rendered from the real generated ../01-tokens/tokens.css via CSS custom properties — nothing is hardcoded. The page runs with the stack down (static; no API, no framework, no build step).

Parameterized. This is direction A. Picking B / C / D / the hybrid is a token-file swap (re-point the <link> to that direction’s tokens.css) + a flip of six variant flags — never a rewrite of this page (00-plan §2). The theme and RTL toggles above prove the same mechanism live: all three theme sets and RTL mirroring re-skin every component below from the one token table. Contrast ratios beside each swatch are measured live from the resolved tokens and re-compute on theme switch. [DEFERRED-UNTIL-USERS] the direction itself is expert-recommended, not user-validated.

Colour & semantic tokens

Surfaces, text, borders, the identity accent, the derived focus/primary token (distinct from accent, §8b.3), the functional status set, and the reserved agent axis. Each swatch is labelled with its token name and its measured contrast against its paired surface (computed live; floors: text 4.5:1, UI/large 3:1).

Elevation

Borders-first: hairlines do nearly all grouping. Shadow is reserved for genuinely floating layers. In high-contrast, shadow is visually inert — a border carries the layer (try the high-contrast theme).

Motion & duration tokens

Functional band ≤240ms, no spring/bounce. The chips below animate continuously on a loop using each duration token. prefers-reduced-motion zeroes every duration (the animation is removed, never the information) — if your OS has reduce-motion on, the chips hold still and show their value statically.

Icon library (the 42 core icons — one monochrome outline style)

Every glyph is inline SVG inheriting currentColor from the token-driven ink, so one drawing serves light / dark / high-contrast and any accent — no per-theme files. Switch the theme above and the whole grid recolours from the same source. The accent control below proves it tracks any colour, not just text ink. Names are the registry contract keys (../04-icons/ICONS-README.md §2 / USAGE-MAP.md); the same glyphs ship as ../04-icons/dist/sprite.svg + manifest.json.

Ink

Agent rail: agent is the plain geometric mark (rounded square + centered dot) — never sparkle / shimmer / star / emoji (§8b.3). Status rail: the ring-enclosed check-pass / check-fail / check-pending trio is the CI verdict set; bare ✓/✗ (approve / reject / close) is action/chrome, paired with a label, never colour-alone.
