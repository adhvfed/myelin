# Icon Library — Review-Refine Pass 4 notes (DEEP geometry-quality)

> **Deep refinement pass.** Built with `strok`. Date: 2026-06-20.
> Focus per brief: make every icon **crisp and precise at large size** by fixing the
> root-cause geometry technique. Style/metaphors and the pass-2 optical-weight rules
> are preserved. Edited `.strok` sources only; SVGs regenerated by `build.sh`. Nothing committed.

## Root cause fixed
Several icons drew **geometric** shapes (rounded rects, circles, arcs, arches, cylinders)
with `mode=catmull-rom` splines threaded through near-collinear points. Catmull-rom
through such points produces **wavy edges, uneven corners, and faceting** — visible only
at large size. The fix is to use the correct primitive per shape:

- Rounded-rectangle UI shapes → `template=rectangle` + `round-corners N`.
- Full circles → `template=ellipse`; **open arcs / true circular curves** → path points
  with `mode=arc rx=R ry=R`.
- Straight connectors → `mode=sharp` segments meeting node circles precisely.
- `catmull-rom` is now used by **no icon** (it was only ever masking geometric shapes here).

Note on `mode=arc` sweep direction: the bulge side depends on point order. For curves
that bulged the wrong way (database bottom/bands, link hooks, rerun) the point order was
reversed to flip the sweep. Verified visually at 256px in every case.

## Per-icon technique changes (before → after)

1. **message** — was a 11-point catmull-rom bubble outline (top edge wavy, corners
   uneven, lumpy tail). Now a clean `rectangle round-corners 3` body (4,5 16×11) + a
   precise 3-point `sharp` tail at bottom-left. Crisp uniform corners.
2. **nav-chat** — was two catmull-rom bubble outlines (both wavy). Now two clean
   `rectangle round-corners 2.5` bubbles (back upper-right, front lower-left) + one sharp
   tail on the front bubble. Stays the "conversation / two bubbles" metaphor, now crisp;
   still distinct from single-bubble `message`.
3. **folder** — was a single path with a **diagonal** tab step + uniform `round-corners 1`,
   which lumped at the slope. Now a right-angle **L-step** tab (vertical drop from tab top
   to body top) with `round-corners 1.5` so every corner rounds uniformly — no lump.
4. **branch** — diverge was a 4-point catmull-rom (wobbly, top-right node overlapped).
   Now a single true `mode=arc` (rx=ry=11) sweeping monotonically from the rail up into the
   top-right node. Nodes unchanged (⌀6).
5. **merge** — converge was a 4-point catmull-rom (wobbly). Now a single `mode=arc`
   (rx=ry=11) from the top-right node down-left into the bottom-left node, mirroring branch.
6. **cycle** — ring was a 9-point catmull-rom "potato". Now a **true circle**: 4 `mode=arc`
   quarter segments (r=8, centered 12,12) with a gap at top; arrowhead = two straight
   strokes at the top-LEFT terminal at the clockwise tangent.
7. **rerun** — arc was an 8-point catmull-rom. Now the **same true-circle** construction as
   cycle but with the arrowhead at the top-RIGHT terminal — opposite handedness keeps the
   two circular-arrow glyphs clearly distinct.
8. **database** — sides + 2 bands were catmull-rom (faceted/polygonal cylinder, flat
   bottom). Now: top `ellipse` (unchanged) + straight sides + a `mode=arc` (rx=7 ry=2.5)
   **bottom curve** bulging down + two `mode=arc` band curves matching the top ellipse's
   curvature. Smooth cylinder.
9. **gate (lock)** — shackle arch was a 5-point catmull-rom (peaked/angular top). Now
   straight legs + a single `mode=arc` (r=4) semicircular arch — uniform, smooth.
10. **link** — two hooks were 5-point catmull-rom C-curves (uneven). Now each hook is a
    single `mode=arc` (rx=6 ry=4) C, symmetric left/right, + the existing center bar.
    Clean chain-link.
